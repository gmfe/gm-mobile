# 大范围任务:目录分片与 subagent 协议

> 按需加载:扫描整个 `src/` 或多个业务模块时阅读。小范围任务(用户指定单文件,或候选文件 ≤8 个)由主流程直接处理,不使用本文件。

## 常量

| 常量 | 值 | 说明 |
|------|----|------|
| `MAX_SUBAGENT` | 8 | 同一消息并行启动的 subagent 上限,取 Agent 工具并发 cap 与单 subagent 上下文预算的折中 |
| `BATCH_FILES` | 8 | 无子目录可拆时,每批最多处理的文件数 |
| `REPORT_LINES` | 300 | 单个分片报告行数上限,防止主上下文被淹没 |

## 目录分片策略

1. 主流程先用 Glob 获取目标目录结构,只划分任务,不读取所有候选源码
2. 默认以一级业务目录为一个分片,例如 `src/js/home/`、`src/js/handle_by_orders/`
3. `src/components/`、`src/services/`、`src/hooks/` 等顶层目录分别作为独立分片
4. 单个目录候选文件过多时继续按直接子目录拆分;没有子目录时每批最多 `BATCH_FILES` 个文件
5. 一个文件只能属于一个 subagent,禁止多个 subagent 重复扫描或修改同一文件
6. 独立目录可以在同一消息中并行启动,最多 `MAX_SUBAGENT` 个;剩余目录分批处理
7. subagent 必须加载本技能完整规则,且只能处理 prompt 中明确列出的目录或文件

## 扫描 subagent 协议

每个目录启动一个只读 subagent。prompt 必须包含:

- 唯一负责的目录或文件列表
- 本技能完整的处理、跳过、调用风格和 locale 规则
- 禁止修改任何文件
- 禁止扫描分片外路径;仅可读取 `i18n.config.js`、`src/locales/zh.json` 和追踪当前目录用途所必需的直接引用
- 只返回结构化结果,不返回完整文件内容、搜索日志或逐步分析;禁止改用其他报告标题或展开逐项跳过明细
- 每条「可安全转换」或「需人工判断」候选只保留一行代码摘要;每个分片报告控制在 `REPORT_LINES` 行以内

### 计数口径(所有数量统一按此)

- 以「中文候选源码位置」计数:同一源码位置即使包含多个中文片段也计 1 处
- 同一位置不得跨分类重复计数
- 候选文件数按至少包含 1 处中文候选的位置所属文件去重计数
- 必须满足不变量:**`中文候选位置 = 可安全转换 + 需人工判断 + 跳过 + 配置排除`**

### 回传格式

下列标题、表头、汇总字段均为 **REQUIRED**;没有条目时保留表头并填写「无」:

```md
## 分片:src/js/home/

### 可安全转换
| 临时编号 | 位置 | 类型 | 当前摘要 | 建议调用 | import 变化 | locale key/value/VARn |

### 需人工判断
| 临时编号 | 位置 | 原因 | 建议 |

### 明确跳过统计
| 原因 | 数量 |

### 项目配置排除
| 路径 | 数量 |

### 汇总
- 候选文件:X
- 中文候选位置:X
- 可安全转换:X
- 需人工判断:X
- 跳过:X
- 配置排除:X
```

## 主流程合并规则

- 只合并各分片的「可安全转换」和「需人工判断」条目,为它们生成全局唯一编号
- 跳过项默认只汇总数量,用户要求时再展开
- 动态 locale 提案合并:以「标准化模板值 + `${VARn}` 出现顺序」作为全局唯一标识,忽略提案 key 名;模板值及占位符顺序完全一致的跨分片提案必须合并并共用一个 key;同一模板出现多个新 key 提案时,由主流程选取语义最通用且稳定的一个。只有「模板不同但 key 相同」才属于冲突
- 主流程不得重复读取 subagent 已确认的全部源码,仅在以下情况复核具体文件:
  - 不同分片提出相同 key 但不同 value
  - 多个动态模板可能复用同一 key
  - import 或调用风格判断存在冲突
  - 用户确认后即将修改该文件

## 修改 subagent 协议(用户确认后)

1. 每个 subagent 只修改自己分片内用户确认的条目
2. prompt 必须列出全局确认编号、文件、行号和已批准的转换形式
3. 修改前重新 Read 文件,内容变化时停止该条目并报告
4. 可以修改分片内源码及对应 `gm-i18n` import
5. 禁止修改 `src/locales/zh.json`、`i18n.config.js` 或分片外文件
6. 禁止顺带处理未确认候选或做无关重构
7. 返回修改文件、完成/跳过编号、动态 locale 提案和验证结果,不返回完整 diff

各 subagent 编辑的是互不相同的源码文件,可在主工作区并行;共享的 `src/locales/zh.json` 始终由主流程收集所有提案、解决冲突后串行写入一次。

## 失败与上下文控制

- 单个 subagent 失败不阻塞其他目录;主流程记录失败目录并单独重试一次或列为未扫描
- subagent 报告超过限制时,应要求其仅返回可转换项、需判断项和统计,不读取完整 transcript
- 不把同一目录重复交给新的 subagent,除非前一个明确失败或用户要求复核
- 目录间没有依赖时并行;修改共享调用链或同一文件时串行
